## Sari-Sari Store Inventory System

### 1. Encapsulation
Encapsulation is the way to organize your code by grouping them into "Objects" which are a group of related functions("methods") and variables("Properties"). Encapsulation is used to prevent a mess of code known as sphagetti code which is so fragile a single change can break the program.

### 2. Abstraction
Abstraction allows for cleaner code which gives the benefit of easier usage and less impact of change meaning when you make a change it wont affect other code. Abstraction is especially useful for when your code gets too large and maintaining becomes a hassle looking for one function.

### 3. Inheritance
Inheritance Helps optimize our code by allowing other code to "inherit" from one original code to prevent the creation of redundant ones. Through inheritance code can be easily shrunk down and makes coding a lot faster.

### 4. Polymorphism
Polymorphism means instead of making it such that the object will hold the ability itself and will not be reliant on an external objects when performing its own task only necessary data like inputs and outputs. Polymorphism makes it that objects can be able to act more independent and allow for times where it will not require external code to run.
